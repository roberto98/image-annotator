### US-005: Viewport Service ✓ COMPLETE
**Status:** Complete
**Started:** 2024-02-03
**Completed:** 2024-02-03

**Changes made:**
- Created `app/static/js/core/Viewport.js` - New viewport service class
- Updated `app/templates/multi_landmark.html` - Updated script path to core/Viewport.js
- Updated `app/static/js/utilities.js` - Updated reference comment
- Removed `app/static/js/services/viewport.js` - Old implementation
- Created backup at `backup/js_services/viewport.js.bak`

**Key Features Implemented:**
- `screenToImage(x, y)` / `imageToScreen(x, y)` - Core coordinate transformations
- `screenToImagePoint()` / `imageToScreenPoint()` - Point object convenience methods
- `setScale(newScale, centerX, centerY)` - Zoom centered on cursor position
- `pan(deltaX, deltaY)` - Pan viewport by delta
- `reset()` - Reset to default state (scale=1, offset=0,0)
- `fitToContainer(imageWidth, imageHeight, containerWidth, containerHeight)` - Fit image to container
- `setState(scale, offsetX, offsetY)` - Batch update viewport state
- `testRoundTrip(screenX, screenY)` - Numerical stability verification (<0.01px error)
- `subscribe(callback)` / `unsubscribe(id)` - Reactive state change notifications
- Comprehensive JSDoc type annotations

**Backward Compatibility:**
- `displayToImage()` / `imageToDisplay()` - Deprecated aliases
- `eventToImage()` - Legacy event coordinate conversion
- `zoom`, `translateX`, `translateY` getters - Legacy property aliases
- `linkState()`, `setContainer()`, `setImage()` - No-op methods with deprecation warnings

**Notes for next developer:**
- Viewport is a singleton exported as `window.viewport`
- Class also exported as `window.Viewport` for testing/extending
- MIN_SCALE=0.1, MAX_SCALE=50.0 are static class properties
- Subscribe pattern similar to AnnotationStore for consistent reactivity

### US-006: SVG Annotation Layer ✓ COMPLETE
**Status:** Complete
**Started:** 2024-02-03
**Completed:** 2024-02-03

**Files Created:**
- `app/static/js/core/AnnotationRenderer.js` - New SVG-based annotation renderer (~1430 lines)
- `app/static/css/annotations/renderer.css` - SVG annotation styles with dark mode support

**Files Modified:**
- `app/static/js/rendering.js` - Updated to delegate to SVG renderer
- `app/static/js/state.js` - Added global COLORS export
- `app/templates/multi_landmark.html` - Updated script loading order

**Files Backed Up:**
- `app/static/js/_backup/renderer.js.bak` - Original annotations/renderer.js
- `app/static/js/_backup/rendering.js.bak` - Original rendering.js

**Key Features Implemented:**
- SVG overlay positioned over image container with proper z-index
- Viewport transform synchronization via CSS matrix transform
- All annotation types rendered: point, line, circle, rectangle, polygon, freehand, angle
- Selection and hover state management with visual feedback
- Measurement label overlay showing distances, radii, angles
- Edit handles for selected annotations (resize/move)
- Comprehensive CSS with dark mode and accessibility support (prefers-reduced-motion)
- Singleton pattern: window.annotationRenderer

**Architecture:**
- Annotations drawn in image coordinates (not screen coordinates)
- Viewport handles zoom/pan transformation via SVG transform group
- Single SVG layer with transform group for rendering efficiency
- Uses mutation-observer pattern to stay in sync with image container

**Notes for next developer:**
- AnnotationRenderer is exported as `window.annotationRenderer`
- Call `annotationRenderer.render(annotations)` to update display
- Subscribe to viewport changes automatically handled
- Edit handles use `data-handle-type` and `data-point-index` attributes
- COLORS from state.js used for consistent annotation coloring

## Phase 3: Basic Annotation Types

### US-007: Point Annotation ✓ COMPLETE
**Status:** Complete
**Date:** 2024-02-03

**Note:** The core point annotation feature was already implemented in the existing codebase. This story focused on verifying functionality and fixing hover integration.

**Existing Implementation (verified working):**
- Point tool button in UI toolbar
- `DrawingHandler.handleClick()` for placing points on single click
- `AnnotationRenderer.renderPoint()` for SVG rendering (circle with crosshair pattern)
- Storage format: `{ type: 'point', data: { x, y } }` in image coordinates
- Label popup integration after point placement

**Fixes Applied:**
- Added `handleMouseOver()` / `handleMouseOut()` event handlers to EditingHandler
  - Calls `annotationRenderer.setHovered(label)` to highlight annotation on hover
  - Clears hover state when mouse leaves annotation
- Added `pointer-events: all` and `cursor: pointer` to annotation groups in AnnotationRenderer.js
  - Without this, SVG elements were not receiving mouse events
- Proper event listener attachment in `EditingHandler.init()`
- Proper event listener detachment in `EditingHandler.cleanup()`

**Files Modified:**
- `app/static/js/annotations/editing.js` - Added hover event handlers and event listener management
- `app/static/js/core/AnnotationRenderer.js` - Added pointer-events for interactivity

**All Acceptance Criteria Met:**
- ✅ Select point tool → single click places marker
- ✅ Visual marker (circle with crosshair) drawn at click location
- ✅ Label popup appears after placement
- ✅ Point stored as { type: 'point', data: { x, y } } in image coordinates
- ✅ Hover shows highlight
